# 模板采集清单（QQ飞车助手）

来源：本清单由程序里所有流程（`Assets/Flows/*.json`）和代码里写死的模板名汇总而成，共 **50 个**（原有 23 个 + 白票相关 27 个）。
当前已采（`templates/` 目录下已有 png + meta.json）：`login_account_box`、`login_password_box`、`login_button`，**还差 47 个**。

> 快速自查：`QQSpeedAssistant.exe --flowcheck` 会把所有流程解析一遍，把「缺哪些模板」写进 `User/debug/flowcheck.txt`，采完再跑一次就知道还差什么。
>
> 认得出但要确认准不准：`QQSpeedAssistant.exe --matchcheck [截图路径]` 会把 `templates/` 里全部模板在一张截图上跑一遍多尺度匹配，逐条列出分数／缩放比／耗时到 `User/debug/matchcheck.txt`。分数 ≥0.85 才算能用；0.5～0.8 一般是框进了会变的内容，重框；<0.4 说明画面里没这东西。
>
> 分辨率不必强求：匹配自动在 0.3～2.6 倍之间找缩放比，实测 800×600 采的模板在 1200×900 窗口上能到 0.99 相似度。

## 一、怎么采（4 步）

1. 把游戏开到要采的那个界面。
   - **登录界面**：不动窗口，按登录窗口原尺寸采集（程序识别出是登录界面会自动跳过缩放）。
   - **游戏内（大厅／玩法／结算）**：登录界面底部要勾「窗口模式」并选 **800x600(32位色)**。程序登录时会用 UIA 自动勾选并对齐这个选项；登录成功后还会把客户区再对齐一次 800x600，采集时也按 800x600 抓。
2. 主界面「玩法任务 → 采集模板」→ 选窗口 → 「抓取画面」。
3. 在预览图上**拖拽框选**要识别的区域 → 填模板名称（必须与下表「模板名」一字不差，不带 `.png`）→ 保存。
4. 保存后程序会自动写 `templates/<名称>.png` 和同名 `.meta.json`（记录采集时的画面宽高，运行时按比例缩放），日志里会打印「模板已保存」。

> 采集窗口抓的是游戏客户区画面，与运行时截图同源，正常情况坐标不会偏。

## 二、框选规则（很关键）

- **只框"永远长得一样"的部分**：图标、按钮文字、面板边框。不要框到会变的数字、倒计时、玩家昵称、头像、动态特效。
- **框得小一点更稳**：一个按钮 40x40 ~ 200x60 足够；框太大容易把背景动画带进来，相似度会掉。
- **避开鼠标悬停高亮**：先把鼠标移开再点「抓取画面」，否则会采到 hover 态。
- **游戏内模板统一在 800x600 下采**：大厅／玩法／结算类模板都以 800x600 客户区为基准（`meta.json` 记录采集时的宽度，运行时按当前宽度缩放匹配）。登录类模板仍按登录窗口原尺寸采，两套互不影响。
- **采完当场验证**：回到同一界面点一次「抓取画面」，能看到对应按钮被识别（日志/流程里相似度 ≥ 0.85）才算合格。

## 四、建议采集顺序（按界面走一遍就行）

1. **登录界面**：补 `login_wrong_password`（故意输错密码一次再采，平时界面不出现）。
2. 登录成功后停在**大厅**：`hall_main` → `hall_multiplayer` → `hall_quick_join` → `hall_create_room` → `hall_setting_button`。
3. 点开**设置**：`setting_logout_button` → `logout_confirm_button` → `setting_video_tab` → `setting_fps_low` → `setting_confirm_button`。
4. 回大厅进**多人游戏 → 快速加入**：`mode_race` → `mode_personal_race` → `match_start_button`。
5. 跑一局到**结算**：`race_finish_panel` → `race_finish_confirm`。
6. 进**创建房间**：`room_mode_team_race` → `room_start_button`；被邀请一次采 `room_accept_invite`、`room_ready_button`。

## 五、采完自查

- `templates/` 下每个模板都是 **png + meta.json 成对**存在，缺 meta 也能用，但窗口缩放时会不匹配。
- 模板名拼错不会有任何报错，只会表现为"流程第 N 步找不到模板"，务必对照本表复制名称。
- 缺模板时点「开始任务」会弹窗列出缺失项；「登录测试」只校验登录那 3 个必填模板。
